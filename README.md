# 🪜 사다리 타기 룰렛

**사다리 타기**는 2~20명이 참여할 수 있는 인터랙티브 웹 기반 사다리 게임입니다. 참가자의 이름과 항목을 입력하면 랜덤하게 생성된 사다리를 통해 각 참가자에게 결과가 자동으로 매칭됩니다.

## ✨ 주요 기능

- **👥 유연한 인원 설정** — `+`/`-` 버튼으로 2명에서 20명까지 자유롭게 조절
- **✏️ 맞춤 입력** — 참가자 이름과 항목을 직접 입력하고 실시간으로 사다리 상단/하단 라벨에 반영
- **🔀 랜덤 사다리 생성** — 매번 다른 패턴의 사다리가 자동 생성 (인접 가로줄 중복 방지)
- **🚀 애니메이션 경로 추적** — 게임 시작 시 각 참가자의 경로가 네온 글로우 효과와 함께 실시간으로 그려짐
- **🎉 결과 모달** — 모든 경로 애니메이션 종료 후 참가자-항목 매칭 결과를 한눈에 확인
- **🔄 리셋 확인** — 실수로 데이터를 잃지 않도록 이중 확인 모달 제공
- **📱 반응형 디자인** — 데스크톱(좌우 분할)과 모바일(상하 배치) 모두 지원

---

## 🖥️ 사용 방법

1. **인원 설정**: `+` / `-` 버튼으로 참가 인원 수를 조절합니다 (2~20명)
2. **이름 입력**: 왼쪽 패널의 "참가자 이름" 필드에 각 참가자의 이름을 입력합니다
3. **항목 입력**: "항목/결과" 필드에 각 항목을 입력합니다
4. **사다리 섞기**: 🔀 **사다리 섞기** 버튼을 눌러 사다리 패턴을 랜덤하게 생성합니다
5. **게임 시작**: 🚀 **게임 시작** 버튼을 누르면 애니메이션이 실행되고 결과가 표시됩니다
6. **초기화**: 🔄 **리셋** 버튼으로 모든 데이터를 초기화할 수 있습니다

## ⚙️ 동작 방식

1. **사다리 데이터 생성** (`generateLadderData`): 각 행(row)마다 45% 확률로 가로줄(bridge)을 생성하되, 같은 행에 인접한 가로줄이 생기지 않도록 보장합니다.
2. **경로 추적** (`tracePath`): 각 참가자의 시작 열(col)에서 아래로 내려가며 가로줄을 만나면 좌우로 이동하여 최종 도착 열을 계산합니다.
3. **애니메이션 렌더링** (`animatePaths`): `requestAnimationFrame` 기반 루프로 모든 참가자의 경로를 동시에 프레임 단위로 그리며, 각 경로는 고유한 색상과 네온 글로우 효과로 표시됩니다.
4. **결과 표시** (`showResults`): 최종 도착 열을 기준으로 참가자-항목 매칭 결과를 동적 그리드 형태의 모달로 보여줍니다.

## 🎨 디자인 특징

- **다크 테마 + 글래스모피즘**: 반투명 패널과 `backdrop-filter: blur()`로 세련된 UI 구현
- **애니메이션 배경 글로우**: 3개의 커다란 블러 그라데이션 원이 배경에서 부드럽게 움직임
- **20가지 고유 경로 색상**: 각 참가자마다 구분되는 생생한 색상 할당
- **커스텀 스크롤바**: 테마에 맞게 스타일링된 스크롤바
- **HiDPI 지원**: `devicePixelRatio`를 고려한 캔버스 렌더링으로 레티나 디스플레이에서 선명하게 출력
